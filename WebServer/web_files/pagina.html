Página de Exemplo

Esta é uma página HTML simples servida pelo servidor HTTP/TCP multithread.

Características do Servidor:

  • Implementação direta com sockets TCP
  • Multithreading para suportar múltiplos clientes simultaneamente
  • Parsing de requisições HTTP GET
  • Respostas HTTP corretas (200 OK, 404 Not Found, etc.)
  • Suporte a diferentes tipos de conteúdo (HTML, JPEG, etc.)
